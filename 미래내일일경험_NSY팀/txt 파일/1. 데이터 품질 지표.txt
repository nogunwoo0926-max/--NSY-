1. 데이터 품질 지표
	1.1 완전성: 데이터의 누락이 없는지 확인. null값, 공백, 빈 문자열, N/A 등을 체크, 값이 필수인 컬럼이 있다면 누락된게 있는지 확인해야하고, 텅 빈 
                       레코드가 있는지도 확인
			데이터 값 완전성, 데이터 레코드 완전성을 확인하자

	1.2 일관성: 데이터의 표현 형식이 모두 동일한가 확인. 날짜 값이 2024/01/01, 2024-01-01와 같이 다르면 안됌. 또 데이터 목록에 정의된 용어만 사용
			되었는지 확인. 공공, 공립과 같은 동의어가 딱 한 단어로만 정해지게 사전에 정의하기

	1.3 유효성: 들어올 수 있는 값의 규칙을 지켰는지 확인. 데이터 타입이 맞는지, 값이 허용 범위 안인지 구분해야함. 테이블의 각 컬럼의 구문 규칙을 
			지정하고, 이 규칙을 벗어난 데이터를 찾아내야한다. 또 컬럼의 유효값을 사전에 지정했다면 유효값 목록에 존재하지 않는 값이 있는지 확인
			각 컬럼 간 또는 테이블 간 관계 규칙이 있을 때, 데이터가 이 관계 규칙을 준수하는지도 확인해야함. 입학일이 졸업일보다 늦으면 안되듯이
			구문 유효성, 의미 유효성, 범위 유효성, 관계 유효성 총 4가지의 유효성을 확인하자

	1.4 이상치: 데이터 분포 값 중에서 상대적으로 튀는 값이 있는지 확인. 틀린 값이 아닐 수도 있고 우선 검토 필요

	1.5 유일성: 고유한 키 값을 받는 컬럼이 있다면 해당 컬럼에서 중복을 체크하면 되고, 행 단위로 모든 컬럼 값이 중복인 행이 있다면 해당 행도 체크해야된다.



2. 각 지표 측정 방안 - (과학기술정보통신부 DQ 인증 가이드라인 인용, 30p부터)
	각 지표의 측정 값은 해당 가이드라인의 정량화 수식인 (1 - 오류 데이터 수 / 진단 총 데이터 수)로 계산한다
