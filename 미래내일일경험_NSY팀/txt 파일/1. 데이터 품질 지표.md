#### 1\. 데이터 품질 지표

1. **완전성**: 데이터의 누락이 없는지 확인. null값, 공백, 빈 문자열, N/A 등을 체크, 값이 필수인 컬럼이 있다면 누락된게 있는지 확인해야하고, 텅 빈 레코드가 있는지도 확인. **셀 단위로 검사**
*데이터 값 완전성(특정 컬럼의 값이 Null/공백 인지), 데이터 레코드 완전성(모든 컬럼이 Null인 빈 행이 있는지), 총 2가지의 완전성을 확인하자
정량화 점수는 전체 셀 기준 결측률을 사용, 빈 레코드가 있으면 추가 정보로 제공*
2. **일관성**: 데이터의 표현 형식이 모두 동일한가 확인. 날짜 값이 2024/01/01, 2024-01-01와 같이 다르면 안됌. 또 데이터 목록에 정의된 용어만 사용되었는지 확인. 공공, 공립과 같은 동의어가 딱 한 단어로만 정해지게 사전에 정의하기. 단위도 고려할 것. **셀 단위로 검사**
*각 컬럼별 데이터 포맷이 일치하는지 확인하자*
3. **유효성**: 들어올 수 있는 값의 규칙을 지켰는지 확인. 데이터 타입이 맞는지, 값이 허용 범위 안인지 구분해야함. 테이블의 각 컬럼의 구문 규칙을 지정하고, 이 규칙을 벗어난 데이터를 찾아내야한다. 또 컬럼의 유효값을 사전에 지정했다면 유효값 목록에 포함되지 않는 값이 있는지 확인. **셀 단위로 검사**
*구문 유효성, 의미 유효성, 범위 유효성 총 3가지의 유효성을 확인하자*
4. **이상치**: 데이터 분포 값 중에서 상대적으로 튀는 값이 있는지 확인. 틀린 값이 아닐 수도 있으니 우선 검토 필요. **행 단위로 검사**
5. **유일성**: 고유키 컬럼 기준 중복 여부와 전체 행 중복 여부를 함께 확인한다. **행 및 키 단위로 검사**

#### 2\. 각 지표 측정 방안 - (과학기술정보통신부 DQ 인증 가이드라인 인용, 30p부터)

&#x09;각 지표의 측정 값은 해당 가이드라인의 정량화 수식인 \*\*(1 - 오류 데이터 수 / 진단 총 데이터 수)\*\*로 계산한다



&#x09;

###### 

###### 이상치 측정 방식

* IQR: 데이터들을 오름차순으로 정렬 후 정확히 4등분 했을 때, 75% 지점의 값과 25% 지점의 값의 차이가 IQR

&#x09;	  25% 지점의 값 - IQR x 1.5 가 하한값 , 75% 지점의 값 + IQR x 1.5가 상한값이다. 이 값의 범위에서 벗어나는 데이터를 이상치로 판별한다

* Z-Score: 계산 방식

&#x09;	- 데이터: \[70, 75, 80, 85, 90] 	- 평균 = 80    - 표준편차 = 7.07

&#x09;	1단계: 평균 구하기          	→ 80

&#x09;	2단계: 각 값에서 평균 빼기  	→ -10, -5, 0, +5, +10

&#x09;	3단계: 제곱하기             	→ 100, 25, 0, 25, 100

&#x09;	4단계: 제곱값의 평균        	→ 50  (이게 분산)

&#x09;	5단계: 루트 씌우기         	→ 7.07 (이게 표준편차)

&#x09;	6단계: z-score 계산		→ Z = (특정 데이터 값 - 평균값)  / 표준편차

&#x09;	Z = 0       → 평균과 완전히 동일한 값

&#x09;	Z = 1\~2     → 평균에서 조금 벗어났지만 정상

&#x09;	Z = 2\~3     → 좀 튀지만 허용 범위

&#x09;	Z = 3 이상  → 이상치로 판정

* Isolation Forest: 계산 방식

&#x09;	1단계: 랜덤하게 컬럼 하나를 선택

&#x09;	2단계: 그 컬럼의 최솟값\~최댓값 사이에서 랜덤하게 선을 그음

&#x09;	3단계: 데이터가 하나만 남을 때까지 반복

&#x09;	4단계: 고립에 필요한 선의 수를 기록

&#x09;	5단계: 이 과정을 수백 번 반복 (Forest = 나무가 많다는 뜻)

&#x09;	정상 데이터 → 평균 10번 선을 그어야 고립됨

&#x09;	이상치      → 평균 2번 선을 그어야 고립됨

###### 수치형 컬럼별로 이상치를 탐지 후, 이상치가 포함된 행을 이상치 행으로 판별한다.

###### 이상치가 검출되면 1, 아니면 0으로 받는다.

1이 한 개면 이상치 의심, 두 개면 이상치로 판단, 세 개면 강한 이상치로 정한다.

이후 **1 - (최종 이상치로 판정된 행 수 / 전체 행 수)로 점수를 산정한다.**



### 각 데이터 품질 지표의 가중치 설정 및 점수 등급 설계

###### 가중치 설정은 다음과 같이 지정한다(DQ 인증 문서에 따라 완전성, 유효성에 높게 주고 일관성, 유일성, 이상치에 낮게 준다)

* 완전성	30%		결측값은 AI 학습 자체를 불가능하게 만드는 가장 치명적인 문제
* 유효성	25%		잘못된 형식/범위의 값은 모델 오류 직결
* 일관성	20%		형식 불일치는 전처리 비용 증가
* 이상치	15%		모델 성능 저하 유발하지만 탐지 후 처리 가능
* 유일성	10%		데이터 편향 유발하지만 상대적으로 처리 쉬움



##### 종합점수 = 완전성×0.30 + 유효성×0.25 + 일관성×0.20 + 이상치×0.15 + 유일성×0.10



##### 등급 기준

###### S : 97점 이상   				→  즉시 AI 학습 가능

###### A : 90점 이상 \~ 97점 미만    →  DQ인증 Class A 기준 (문서 직접 인용 가능)

###### B : 80점 이상 \~ 90점 미만    →  경미한 보완 후 사용 가능

###### C : 70점 이상 \~ 80점 미만    →  상당한 전처리 필요

###### F : 70점 미만  					→  AI 학습 부적합



##### 구현에 추가적으로 정의가 필요한 부분

1. 일관성 - 포맷 기준을 어떻게 정하는가? 사용자가 직접 정하든지, 시스템으로 정하든지
2. 유효성 - 데이터 값 허용 범위는 어떻게 정하는가
3. 유일성 - 키 컬럼 지정을 어떻게 할지도 정해야함
